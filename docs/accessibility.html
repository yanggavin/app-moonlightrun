Accessibility

Effective date: March 19, 2026

MoonlightRun is designed to keep common running tasks readable and operable with Apple accessibility features. This page describes the support currently available and the areas still being improved.

Current Support

  • VoiceOver labels, values, and hints on core screens including ready, live run, history, summary, detail, onboarding, and settings
  • Dark interface across the primary app experience
  • Primary actions use standard controls with touch targets sized for comfortable interaction
  • Optional spoken distance and pace updates during a run

In Progress

  • Larger Text support is being expanded and re-tested across all screens
  • Accessibility verification continues with VoiceOver and related iOS accessibility settings in each release

MoonlightRun does not claim full accessibility coverage. Accessibility information in App Store Connect is limited to features that have been verified for common tasks.

Need Help?

If you find an accessibility issue or need help using MoonlightRun, contact support@moonlightrun-app.newtree.tech.
